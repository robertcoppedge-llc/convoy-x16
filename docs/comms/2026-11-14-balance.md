# Balance — read the session file

Project-X16 edits `x16project.json` `balance` and writes `src/balance.h`. `build-win.cmd` runs `tools/write-balance.ps1` first. `src/game.h` includes that header. Torpedo speed and run (`TORP_SPEED`, `TORP_LIFE`) are live.

Everything else on the Balance page is gray (`"pending": true`). The header defines it. `src/game.c` does not read it. An eel still sinks any ship it touches, and the boat still dies at 3 hits shared by the deck gun and the depth charge.

Wire the symbols, then delete `"pending": true` on each field you connected.

Hulls, in `sink` and the shot loops:

- A torpedo hit on a ship adds `TORP_DMG` instead of sinking outright. Escort, Liberty, and tanker sink at `ESCORT_HITS`, `LIBERTY_HITS`, and `TANKER_HITS`. Tonnage stays `LIBERTY_TONS` and `TANKER_TONS` (the `2 : 1` in `add_tonnage`).
- The boat's hit counter is per type: `BOAT_II_HITS`, `BOAT_VIIC_HITS`, `BOAT_IXC_HITS`, `BOAT_XXI_HITS`. The escort gun adds `ESCORT_GUN_DMG`. A depth charge adds `DC_DMG`. They no longer share one counter of 3 unless those values say so.

Weapons, the literals in `game_tick` and the spawners:

- Torpedo touch radius `12` is `TORP_HIT`.
- Escort shell life `32`, speed `96`, touch `14`, and `cool_gun = 20` are `ESCORT_GUN_FLIGHT`, `ESCORT_GUN_SPEED`, `ESCORT_GUN_HIT`, `ESCORT_GUN_COOL`.
- Depth-charge life `28`, blast `16`, and `cool_drop = 28` are `DC_FUSE`, `DC_BLAST`, `DC_COOL`.
- `boats[]` knots, tubes, and the gun flag are `BOAT_*_SURF`, `BOAT_*_SUB`, `BOAT_*_BOW`, `BOAT_*_STERN`, `BOAT_*_GUN`. The plot still uses the telegraph. The U-boat gun (`BOAT_GUN_DMG`, `BOAT_GUN_HIT`) stays unused until that gun fires, and only on a type whose gun flag is 1.

`make` does not run the header script. A Windows build does.
